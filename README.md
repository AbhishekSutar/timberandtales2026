# Timber & Tales

Responsive storefront built with Angular 22.

## Run locally

1. Install Node.js 22.22.3+ (Angular 22 requirement) and pnpm.
2. From this folder, run `pnpm install`.
3. Run `pnpm start` and open the local URL printed by Angular CLI.
4. Run `pnpm build` for a production build.

The product entries, categories, prices, and image URLs are sample content in `src/app/app.component.ts`. Replace those with your final catalog before publishing. Images currently load from Unsplash, and fonts load from Google Fonts.
